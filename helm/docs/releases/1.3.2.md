## [1.3.2](https://github.com/Cloudzero/cloudzero-agent/compare/v1.3.1...v1.3.2) (2026-11-24)

Release 1.3.2 is a maintenance release that fixes workload label and annotation collection with the built-in KubeState collector, updates the bundled Grafana Alloy to v1.22.0, and includes Go toolchain, dependency, and security updates.

### Bug Fixes

- **Workload Labels and Annotations**: Fixed an issue where enabling collection for Deployments, StatefulSets, DaemonSets, Jobs, or CronJobs had no effect when using the built-in KubeState collector. Labels and annotations on these workloads are now collected when their resource toggles are enabled, without requiring the webhook server. The toggles remain disabled by default.

### Upgrade Steps

If you use a custom ClusterRole (`server.useExistingClusterRoleName`) with `components.agent.kubeState.enabled`, ensure it grants `watch` on each workload resource enabled under `insightsController.labels.resources` or `insightsController.annotations.resources`. The chart adds these permissions automatically when it manages the ClusterRole.

To upgrade to version 1.3.2, run the following command:

```sh
helm upgrade --install <RELEASE_NAME> cloudzero/cloudzero-agent -n <NAMESPACE> --create-namespace -f configuration.example.yaml --version 1.3.2
```
