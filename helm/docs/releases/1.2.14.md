## [1.2.14](https://github.com/Cloudzero/cloudzero-agent/compare/v1.2.13...v1.2.14) (2026-08-10)

Release 1.2.14 is a maintenance release: it fixes an install issue in an experimental configuration and corrects two webhook-related bugs. It also updates dependencies for security and reliability. It introduces no breaking changes and requires no configuration changes.

### Bug Fixes

- **Install with the webhook server disabled**: The optional `components.webhookServer.enabled: false` setting, an experimental feature introduced in 1.2.12, could break the install because the config-loader job was handed an empty `--config-webhook` path. The job now tolerates an empty webhook config path. Default installs run the webhook server and were unaffected.

- **`CloudZeroWebhookNoEvents` false alarms**: Part of the optional monitoring infrastructure, this alert now applies to the aggregate of all webhook servers instead of each instance, eliminating false positives.

- **Webhook diagnostics accuracy**: The `anaximander` debugging script now distinguishes a missing `ValidatingWebhookConfiguration` from a permission error that prevented the script from retrieving it.

### Upgrade Steps

To upgrade to version 1.2.14, run the following command:

```sh
helm upgrade --install <RELEASE_NAME> cloudzero/cloudzero-agent -n <NAMESPACE> --create-namespace -f configuration.example.yaml --version 1.2.14
```
