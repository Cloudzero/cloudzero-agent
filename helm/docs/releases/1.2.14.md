## [1.2.14](https://github.com/Cloudzero/cloudzero-agent/compare/v1.2.13...v1.2.14) (2026-08-10)

Release 1.2.14 fixes a bug that could block installation when the webhook server is disabled (for example, on GCP), and rolls up a round of security and dependency updates. It patches two known Go vulnerabilities, refreshes the embedded Alloy binary and Go toolchain, and updates dependencies across the Go modules, GitHub Actions, and tooling. There are no breaking changes and no required configuration changes.

### Bug Fixes

- **Install no longer blocked when the webhook server is disabled**: When the webhook server is turned off (via `components.webhookServer.enabled`, introduced in 1.2.12), the config-loader job could fail because it was handed an empty `--config-webhook` path. The job now tolerates an empty webhook config path, so installs that disable the webhook surface — including on GCP — no longer error out. Default installs, which run the webhook server, were unaffected.

### Security Improvements

- **`golang.org/x/net` → v0.56.0**: Addresses [GO-2026-5942](https://pkg.go.dev/vuln/GO-2026-5942) / CVE-2026-46600.
- **`golang.org/x/text` → v0.39.0**: Addresses [GO-2026-5970](https://pkg.go.dev/vuln/GO-2026-5970). Applied to the agent's own module and carried as an explicit override into the vendored `prometheus-config-reloader` build (pinned at v0.91.0), so the reloader binary shipped in the agent image picks up the patched version rather than its older transitive pin.
- **Embedded Alloy → v1.18.1**: The CloudZero-maintained Alloy binary copied into the agent image is updated from v1.17.0 to v1.18.1, pulling in upstream fixes and dependency updates.

### Build and Infrastructure

- Go toolchain (Alpine build image) updated to 1.26.5
- Prometheus libraries updated to 0.313.2 (`prometheus/prometheus`), 0.70.1 (`prometheus/common`), and 1.24.1 (`prometheus/client_golang`)
- Kubernetes client libraries (`k8s.io/api`, `k8s.io/apimachinery`, `k8s.io/client-go`) aligned at v0.36.3
- `sigs.k8s.io/gateway-api` updated to v1.6.1
- Additional Go module updates: `go-chi/chi/v5` to v5.3.1, `mattn/go-sqlite3` to v1.14.49, `golang.org/x/sync` to v0.22.0
- Base image bumped to the latest `distroless/static-debian12` digest
- Dependency updates across GitHub Actions (`actions/setup-go` v7, `docker/metadata-action`, `docker/setup-buildx-action`) and tooling (`gofumpt`, `prettier`, `markdownlint-cli2`, `js-yaml`)

### Upgrade Steps

To upgrade to version 1.2.14, run the following command:

```sh
helm upgrade --install <RELEASE_NAME> cloudzero/cloudzero-agent -n <NAMESPACE> --create-namespace -f configuration.example.yaml --version 1.2.14
```

Because this release patches known Go vulnerabilities in `golang.org/x/net` and `golang.org/x/text`, we recommend upgrading promptly.
