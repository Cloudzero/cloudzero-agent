## [1.3.0](https://github.com/Cloudzero/cloudzero-agent/compare/v1.2.14...v1.3.0) (2026-10-01)

Release 1.3.0 marks clustered mode as stable, improves clustered mode autoscaling, and contains reliability and dependency updates.

### Key Features

- **Clustered Mode is Stable**: Clustered mode is no longer experimental and is supported for production use. To enable it, set `components.agent.mode` to `clustered`. Existing installations keep their current mode.

- **Ephemeral Storage Requests and Limits**: Chart components now support `ephemeral-storage` in their resource requests and limits, alongside CPU and memory. When `aggregator.database.emptyDir.sizeLimit` is set, the aggregator also requests that much ephemeral storage (unless you set the request explicitly), so it is scheduled only on nodes with room for its metric files.

### Bug Fixes

- **Clustered Mode Autoscaling**: Fixed an issue where clustered mode replicas did not divide collection work among themselves. Each replica collected the entire cluster, so adding replicas did not reduce the load on any of them: the autoscaler climbed to `maxReplicas` and stayed there, and the aggregator received a copy of every metric from each replica. Now each replica handles only its share, and the autoscaler can settle at the replica count the cluster needs. Every replica still watches all objects in the cluster, so memory use per replica still grows with cluster size; very large clusters may need a higher memory request.

### Upgrade Steps

To upgrade to version 1.3.0, run the following command:

```sh
helm upgrade --install <RELEASE_NAME> cloudzero/cloudzero-agent -n <NAMESPACE> --create-namespace -f configuration.example.yaml --version 1.3.0
```
