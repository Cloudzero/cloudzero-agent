## [1.3.1](https://github.com/Cloudzero/cloudzero-agent/compare/v1.3.0...v1.3.1) (2026-10-21)

Release 1.3.1 is a maintenance release that updates the bundled CA certificates in response to the [eMudhra Intermediate CA Compromise](https://emudhra.we-have-a-problem.com/), along with the Go toolchain, dependencies, and the bundled Grafana Alloy (v1.21.0). It introduces no breaking changes and requires no configuration changes.

### Upgrade Steps

To upgrade to version 1.3.1, run the following command:

```sh
helm upgrade --install <RELEASE_NAME> cloudzero/cloudzero-agent -n <NAMESPACE> --create-namespace -f configuration.example.yaml --version 1.3.1
```
